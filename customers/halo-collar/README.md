# Protect Animals With Satellites, LLC (dba Halo Collar)

**Industry:** Pet Technology / IoT
**Headquarters:** Woodcliff Lake, New Jersey (US operations in Plano, Texas)
**Founded:** 2018
**Website:** halocollar.com

## Overview
Halo Collar develops AI-powered smart collars for dogs that combine GPS tracking, activity monitoring, and training feedback using satellite technology. The system uses proprietary global satellite GPS/GNSS systems to create virtual wireless fences and deliver real-time prevention and encouragement feedback to keep dogs safely contained.
