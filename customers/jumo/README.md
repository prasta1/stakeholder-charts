# JUMO GmbH & Co. KG

**Industry:** Industrial Sensor & Automation Technology
**Headquarters:** Fulda, Germany

## Overview
JUMO is a leading provider of industrial sensor and automation solutions serving manufacturing, process control, and monitoring applications globally. With 2,500+ employees across 25 subsidiaries in 60+ countries, JUMO specializes in temperature, pressure, flow, and liquid analysis measurement systems, along with thyristor/SSR controllers and advanced process automation platforms. The company recently invested in Single Pair Ethernet (SPE) sensor technology enabling direct cloud connectivity.
